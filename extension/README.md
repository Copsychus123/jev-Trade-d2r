# 擴充功能（Chrome）

在**自己的 Chrome** 裡，用自己的 Traderie 登入，查詢暗黑 2 裝備的「目前掛單」和「近期成交」，整理成兩張表，可下載 CSV。擴充功能裡沒有任何 Jev 金鑰；金鑰在 `services/` 的後端。

## 打包

```
uv run python extension/build.py --api https://jev-trade-d2r.vercel.app
```

- `--api` 換成實際部署的網址；省略時用上面的預設值。
- 結果在 `extension/dist/`，另外產生 `extension/jev-traderie-extension.zip` 可以直接傳給朋友。
- 打包時會自動檢查，裡面如果出現金鑰或密碼字串，就會失敗並且不產生 zip。

## 安裝（每個人做一次）

1. 解壓縮 zip（或直接用 `extension/dist/`）。
2. 開啟 `chrome://extensions`，打開右上角的「開發人員模式」。
3. 按「載入未封裝項目」，選解壓縮後的資料夾。
4. 在同一個 Chrome 登入 Traderie（<https://www.traderie.com>）。

## 使用

1. 按工具列的擴充功能圖示，右側會開出側邊欄。
2. 第一次輸入邀請碼，按「儲存」。
3. 輸入裝備名稱（英文，例如 Harlequin Crest），選「載入更多次數」（0 到 5，預設 2；每多按一次，每段多讀 50 筆掛單、20 筆成交，約多 8 秒），按「開始查詢」。查詢中這些欄位會鎖住。
4. 會另開一個**最小化的視窗**放 Traderie 並自動操作，不會蓋住你正在做的事。**查詢期間請不要關掉側邊欄，也不要關掉那個最小化視窗。**
5. 那個視窗上方的「正在偵錯此瀏覽器」黃色橫幅是正常的（無法隱藏）；查詢結束會自動關掉視窗。
6. 如果 Traderie 跳出安全驗證（Cloudflare）或要你登入，查詢會停止並提示。請自己在 Chrome 開 Traderie 處理完，再按開始。
7. 找商品分三層，每層只試一次，結果下方會寫「查詢方式」：
   - **查表直接開啟**：名稱在內建對照表裡，直接開商品頁（不問 Jev），再檢查頁面標題是不是那個商品，不是就改用搜尋。
   - **站內搜尋**：Jev 在搜尋欄輸入名稱並挑結果。
   - **底材清單**：搜尋出現「No results could be found」時，Jev 從固定的底材清單挑一個（例如查 Rare Ring 會挑 Ring），再搜一次；畫面會註明「顯示的是底材，沒有依品質篩選」。清單裡沒有適合的，就顯示「找不到這個裝備」並結束。
   也可以輸入繁體中文裝備名稱，會先用對照表換成英文；表裡沒有的中文名稱不會開始查詢，也不會用掉次數。
8. 完成後兩張表會顯示結果。超過 10 筆時每頁顯示 10 筆，表格下方有「上一頁／下一頁」。每張表右上有「複製」（貼到試算表會分欄）、「前往網站」（在新分頁開這張表讀取的 Traderie 頁面，查詢完成後才能按）和「下載 CSV」，這兩個都會包含**全部筆數**，不只是目前這一頁。

### 用截圖查名稱

「裝備名稱」欄右邊有一顆「📷 截圖」鈕：按它選一張物品提示框的截圖，或在側邊欄按 Ctrl+V 貼上、把圖拖進來。放進圖片後，名稱欄下方會展開「截圖辨識」區（可按「✕ 收起」，沒有圖片時看不到它）。按「辨識」後，程式在你的電腦上把圖裡的字讀出來（不會把圖傳到任何網站），**把最像的名稱直接填進「裝備名稱」欄**，名稱欄下會出現「來自截圖，請確認」的小標籤（你自己改過名稱後標籤就消失），辨識區另外列出其他 1 到 2 個候選（點一下就改填那個）。**不會自動查詢**，你確認名稱沒問題後，自己按「開始查詢」。

- 第一次使用某個語言會先問你：「首次使用「繁體中文」需下載辨識模型（約 1.7 MB…）」。同意後才下載一次，存在這個瀏覽器裡，下次不用再下載；下載來源是固定的網址，下載後會檢查檔案是否完整，不符就丟掉。
- 下載失敗會直接顯示原因，不會自己重試；可以再按一次「辨識」，或用「下載不了？手動匯入模型」選對應的 `<語言代碼>.traineddata.gz`（例如 `chi_tra.traineddata.gz`、`eng.traineddata.gz`，同樣會檢查）。
- 圖上可以拖一個框，只讀框裡的字（物品名稱那幾行），通常更準更快。
- 稀有、魔法、手工裝備的名稱是隨機的，Traderie 沒有這個商品；這時只會認出「底材」（戒指、護身符、特大咒符…），畫面會寫「只認出底材，不會依品質篩選」。
- 「截圖上的遊戲語言」可選：繁體中文（預設）、English、简体中文、日本語、한국어、Deutsch、Français、Español。每種語言**第一次選用時才下載**（約 0.7 到 2.9 MB），下載後存在這個瀏覽器裡，**之後完全離線也能辨識**；選單裡已下載的語言會標「已存在本機，可離線」。一次只讀一種語言（兩種一起讀，我量過反而比較不準）。
- 注意：程式只能把圖上的字讀出來；**比對成 Traderie 的商品，只對繁體中文名稱與英文名稱有效**（我們的對照表只有這兩種）。其他語言的遊戲，如果截圖上沒有英文名稱，讀出來的字會顯示在「看辨識出的文字」，名稱要自己手動輸入。
- 辨識不一定每次都對，所以一定要你確認。看「看辨識出的文字」可以知道程式讀到了什麼。

## 常見訊息

| 訊息 | 意思 |
|---|---|
| 邀請碼無效或已停用 | 碼打錯，或已被停用 |
| 今天的 100 次查詢已用完 | 台灣時間午夜 0 點重置 |
| 需要登入 | 這個 Chrome 還沒登入 Traderie |
| 查詢視窗被關閉或偵錯被取消，查詢已停止 | 查詢中途關了那個最小化視窗，或按了黃色橫幅的「取消」 |

## 開發

```
node --test "extension/test/*.test.mjs"      # 迴圈與讀取邏輯
uv run pytest scripts/tests/test_extension_parity.py   # 解析結果和 Python 版逐筆相同
uv run python scripts/extension_e2e.py   # 真實 Chrome 端對端（預設無視窗，--headed 顯示視窗）
```

端對端測試需要專用 Chrome 已登入 Traderie（`uv run python login.py`），執行時會先關掉正在跑的專用 Chrome。

資料夾：`src/` 是程式；`page/*.js` 打包時從 `core/jev_ultrafast/` 複製（和本機 Python 版共用同一份頁面腳本）。

## 更新對照表

內建的「名稱 → 商品網址」「中文 → 英文」「底材清單」存在 `src/traderie/data/items.json`，是某個時間點的拷貝。遊戲或網站新增物品後，重新產生：

```
uv run python scripts/build_item_tables.py
```

會開專用 Chrome 讀 Traderie 和 d2r.world，結果寫進上面那個檔案，並把「對不上的名單」放在 `artifacts/item_tables_report.json`。表過期的後果只是少一層捷徑（退回搜尋），不會查錯。更新後要重新打包（`extension/build.py`）。
