# 擴充功能（Chrome）

在**自己的 Chrome** 裡，用自己的 Traderie 登入，查詢暗黑 2 裝備的「目前掛單」和「近期成交」，整理成兩張表，可下載 CSV。擴充功能裡沒有任何 Jev 金鑰；金鑰在 `services/` 的後端。

## 打包

```
uv run python extension/build.py --api https://jev-trade-d2r.vercel.app
```

- `--api` 換成實際部署的網址；省略時用上面的預設值。
- 結果在 `extension/dist/`，另外產生 `extension/jev-traderie-extension.zip` 可以直接傳給朋友。
- 打包時會自動檢查，裡面如果出現金鑰或密碼字串，就會失敗並且不產生 zip。

## 安裝（每個人做一次）

1. 解壓縮 zip（或直接用 `extension/dist/`）。
2. 開啟 `chrome://extensions`，打開右上角的「開發人員模式」。
3. 按「載入未封裝項目」，選解壓縮後的資料夾。
4. 在同一個 Chrome 登入 Traderie（<https://www.traderie.com>）。

## 使用

側邊欄一次只顯示一個畫面。最上面一列永遠看得到：標題、右邊的用量（例如「剩 97 次」；查詢中和查完後顯示「已用 3/100」），以及 ⚙ 設定鈕（查詢中不能按）。

1. 按工具列的擴充功能圖示，右側會開出側邊欄。
2. **第一次**會看到「歡迎！先輸入邀請碼」：貼上邀請碼，按「確認並開始使用」。這時邀請碼只暫時放在畫面裡，**等第一次查詢被伺服器接受後才會儲存**，所以打錯的碼不會被記下來；打錯或被停用時會回到這個畫面並說明原因。
3. 輸入「裝備名稱」（中文或英文都可以，也可以貼上截圖，例如 Harlequin Crest）。「多讀幾批」用 − / + 選 0 到 5（預設 0；每多一批，每段多讀 50 筆掛單、20 筆成交，約多 8 秒）。按「開始查詢」。
4. 查詢中，輸入畫面會縮成一行「查詢：名稱」，「開始查詢」變成「停止」，下面用四個步驟（找到商品、讀取目前掛單、讀取近期成交、核對資料）顯示進度：✔ 完成、● 進行中、○ 還沒開始、✖ 失敗。輸入欄、批數和設定都會鎖住。按「停止」會顯示「已停止」，已經讀到的資料仍然保留。
5. 會另開一個**最小化的視窗**放 Traderie 並自動操作，不會蓋住你正在做的事。**查詢期間請不要關掉側邊欄，也不要關掉那個最小化視窗。**
6. 那個視窗上方的「正在偵錯此瀏覽器」黃色橫幅是正常的（無法隱藏）；查詢結束會自動關掉視窗。
7. 如果 Traderie 跳出安全驗證（Cloudflare）或要你登入，查詢會停止，上方出現紅框說明。按「開啟 Traderie」在新分頁處理完，再回側邊欄按「我處理好了，重新查詢」（不會自動開始）。
8. 找商品分三層，每層只試一次，查完後核對結果那一行會寫「查詢方式」：
   - **查表直接開啟**：名稱在內建對照表裡，直接開商品頁（不問 Jev），再檢查頁面標題是不是那個商品，不是就改用搜尋。
   - **站內搜尋**：Jev 在搜尋欄輸入名稱並挑結果。
   - **底材清單**：搜尋出現「No results could be found」時，Jev 從固定的底材清單挑一個（例如查 Rare Ring 會挑 Ring），再搜一次；畫面會註明「顯示的是底材，沒有依品質篩選」（這行提醒一直留在核對結果下面）。清單裡沒有適合的，就顯示「找不到這個裝備」，並建議「試試英文全名，或用截圖」。
   也可以輸入繁體中文裝備名稱，會先用對照表換成英文；表裡沒有的中文名稱不會開始查詢，也不會用掉次數。
9. 查完後，名稱那一行右邊有「重新查詢」（回到輸入畫面，名稱保留，舊結果在你下次開始查詢前還看得到）。它下面是核對結果：「✔ 資料已核對 · 查詢方式 · 讀取時間」；如果有資料沒通過核對，會是「⚠ 部分資料沒通過核對 ›」，點開會用白話列出哪裡沒通過。
10. 結果分成兩個分頁（可用滑鼠點，或用鍵盤左右鍵切換）：「目前掛單 N」和「近期成交 N」（N 是筆數，開了篩選會變成「12/50」，也就是「留下幾筆/讀到幾筆」；那一段沒讀成功時，旁邊會標「讀取失敗」或「被網站擋住」）。分頁列正下方有一排三個等寬按鈕「下載 CSV」、「複製」（貼到試算表會分欄）、「前往網站」（在新分頁開這個分頁讀取的 Traderie 頁面），它們**作用在目前選到的分頁**，切換分頁就換成那一段；那一段沒有資料時「下載 CSV」和「複製」是灰的，沒有網頁位址（查詢完成前）時「前往網站」是灰的。複製和 CSV 都會包含**篩選後的全部筆數**（沒開篩選就是讀到的全部），不只是目前這一頁。每個分頁下面直接是清單（超過 10 筆時每頁 10 筆，用「‹ ›」換頁）；只有那一段是空的或沒讀成功時，清單位置才會多一行說明原因（例如「目前沒有掛單」、「需要登入」）。
    - 目前掛單每筆用兩行顯示：第一行是要價和賣家，第二行是刊登時間、平台／模式／天梯，還有遊戲版本，有的話再加上高符文價值和防禦（沒有的就不顯示）。畫面、複製和 CSV 用的是同一份資料，CSV 另外多了「遊戲版本」這一欄。
    - 近期成交也是兩行：第一行是成交物品和成交價格，第二行是成交時間、平台／模式／天梯、遊戲版本（沒有的就不顯示）。
    - 開了篩選時，分頁列上方會多一行「篩選中：PC · Softcore · Ladder　隱藏 38 筆　改」（隱藏幾筆是看目前選到的分頁；若其中有網站沒標示的資料，會註明幾筆；留下不到 10 筆而網站上還有更多時，會提醒到首頁調高「多讀幾批」）。「改」會打開設定。篩選到一筆都不剩時，清單位置會寫「篩選後沒有符合的資料（原本讀到 N 筆）」，旁邊有「清除篩選」。

### 設定（⚙）

- **邀請碼**：只顯示遮住的樣子。按「更換」輸入新的碼再按「確認」；新的碼同樣要等下一次查詢被接受後才會儲存。
- **用量**：已知時會顯示已用幾次、剩幾次。
- **篩選（只影響畫面、複製和 CSV）**：平台、模式、天梯、遊戲版本各有一個選單（預設「不限」），另有「常用：PC · Softcore · Ladder」和「清除」。兩個分頁都會套用。篩選是在網站讀完之後才做的：改篩選**不會重新查詢、不會用掉次數**，也不影響「資料已核對」的判斷（核對用的是讀到的全部資料）。網站沒標示某一項的資料，在那一項有篩選時會被隱藏。設定會記住，下次打開還在。
- **截圖辨識**：引擎是 PP-OCRv6（中、英、日、韓等共用一個模型）、決定「放入圖片後自動辨識」要不要開（預設開）；第一次使用需下載模型（約 31.8 MB）。
- **學習紀錄**：你在截圖辨識或裝備掃描裡點選過、或自己輸入過的名稱，會記在這台電腦上（說明在下一節「程式沒有把握時」）。這裡寫著目前記了幾筆、其中幾筆已經選過兩次以上；按「清除學習紀錄」會先問一次「確定全部清除嗎？」，按「確定清除」才會清掉；按「看看記住了什麼」可以看最新的 30 筆（寫著程式讀到什麼字、你選的是哪個名稱、選過幾次），每一筆右邊的「✕」可以只刪掉那一筆（例如點錯了）。**這些只存在這台電腦裡，不會傳到任何地方，也不會存圖片或整段辨識文字。**
- **Traderie 屬性清單**：只顯示上次讀取的日期與項數（模糊搜尋查法用）；不用手動更新，超過 7 天會在下一次查詢時重讀。

### 用截圖查名稱

「裝備名稱」欄右邊有一顆「📷」鈕：按它選一張物品提示框的截圖，或在側邊欄按 Ctrl+V 貼上、把圖拖進來。放進圖片後，名稱欄下方會出現小縮圖（點一下放大，可按「✕」收起；沒有圖片時看不到）。程式在你的電腦上把圖裡的字讀出來（不會把圖傳到任何網站），**把最像的名稱直接填進「裝備名稱」欄**，名稱欄下會出現「● 來自截圖，請確認」的小標籤（你自己改過名稱後標籤就消失），縮圖下方另外列出其他 1 到 2 個候選，按鈕上先寫中文、括號裡是英文（例如 `權冠（Diadem）`、`防禦盾（Defender）`；表裡沒有中文名時只寫英文），點一下就改填那個。名稱欄裡填的也是中文名（沒有中文名才填英文）；不管欄裡是中文還是英文，實際到 Traderie 查詢時一律用英文名稱。**不會自動查詢**，你確認名稱沒問題後，自己按「開始查詢」。

- 預設「放入圖片後自動辨識」是開的：模型已經在這個瀏覽器裡時，放入圖片就會自己讀，不用按鈕。只有在關掉自動辨識、模型還沒下載（或你在圖上拖了框想重讀）時，才會出現「辨識」鈕。縮圖下方的「看辨識出的文字」可以看程式讀到了什麼：每一行都照原樣列出，認得出的裝備名稱後面會多附上中文（例如 `Ripsaw（鋸齒刃）`）。
- 第一次使用會自動下載辨識模型（約 31.8 MB），下載會自己完成，畫面不會顯示進度或取消鈕；只下載一次，存在這個瀏覽器裡，之後可離線使用；下載來源是固定的網址，下載後會檢查檔案是否完整，不符就丟掉。
- 下載失敗會直接顯示原因，不會自己重試；可以再按一次「辨識」重新下載；模型紀錄會在引擎啟動失敗時自動清除。
- 圖上可以拖一個框，只讀框裡的字（物品名稱那幾行），通常更準更快。
- 稀有、魔法、手工裝備的名稱是隨機的，Traderie 沒有這個商品；這時只會認出「底材」（戒指、護身符、特大咒符…），畫面會寫「只認出底材，不會依品質篩選」。要查這類裝備，請改用上面的「模糊搜尋（適用黃・藍・白裝）」查法（見下一節）。
- 注意：程式只能把圖上的字讀出來；**比對成 Traderie 的商品，只對繁體中文名稱與英文名稱有效**（我們的對照表只有這兩種）。其他語言的遊戲，如果截圖上沒有英文名稱，讀出來的字會顯示在「看辨識出的文字」，名稱要自己手動輸入。
- 辨識不一定每次都對，所以一定要你確認。
- **程式沒有把握時，會列出「可能是」的名稱讓你選。**除了它最像的 1 到 3 個，還會再補上名稱差不多的，一共最多 5 個（讀錯幾個字、或根本沒認出名稱時也會列）；按鈕先寫中文、括號裡是英文，**你點哪一個，才會填哪一個**，程式不會替你決定。三個字以內的短名稱（例如「力量」）很容易和一般文字混在一起，不會用「差不多」的方式補進這份清單。
- **程式會記住你的選擇，下次同樣的辨識結果就用得上。**你點過、或自己輸入過的名稱，會連同「程式當時讀到的那行字」記在這台電腦上。下次讀到**完全一樣**的字時，你選過的名稱會排在第一個，旁邊寫「你上次選過這個」，**但還是會問你**；連續兩次都選同一個名稱、中間沒有改選別的，第三次才會自己填好（畫面寫「照你之前的選擇」）。只選過一次，或中間改選過別的，都不會自動填，所以不小心點錯一次不會變成一直填錯。它只對**同一個讀錯的字**有用（例如某個字老是被讀成同一個錯字），讀到的字只要差一個字就不算；也救不回「根本沒被偵測到的提示框」。要清掉或刪掉其中一筆，到「⚙ 設定」的「學習紀錄」。

### 模糊搜尋（適用黃・藍・白裝，用詞綴查）

打開側邊欄先問「今天想搜尋什麼？」，選「模糊搜尋」進入模糊搜尋表單。名稱欄變成「底材名稱」（不可空），下面多出品質和詞綴條件，**不再有「多讀幾批」**（只讀第一頁，最多 50 筆）。

1. 貼上或拖入裝備截圖（同一顆 📷 鈕），也可以在底材欄直接手動輸入。底材欄**已支援繁體中文輸入自動轉換**（例如輸入「戒指」、「權冠」會自動轉成「Ring」、「Circlet」）。如果認出的是傳奇或套裝名稱，會自動切到精準搜尋表單。
2. 程式把圖上的詞綴行轉成一排條件；數字有把握的會自動勾上，不確定的留著給你確認：每列有勾選框、最小值、最大值和 ✕。標「?」的列表示數字讀得不確定（常見的是 % 被讀成多餘的數字），已填的數字只是參考，請自己確認；灰色、不能勾的列表示 Traderie 沒有這個屬性。也可以用「新增條件…」選單手動加。最多同時勾 8 條。
3. 品質：不指定、黃裝（稀有）、藍裝（魔法）、白裝（普通與優秀）。
4. 勾好條件、改好數字後按「開始查詢」。「從截圖填入」鈕可以重新讀一次圖上的詞綴（你勾過的條件和改過的數字會保留）。

這個查法是用 Traderie 首頁的「Search All Stats」篩選（程式把你確認的條件組成網址再打開），所以：不呼叫 Jev、不扣邀請碼的次數；Traderie 的屬性清單要在你已登入的 Traderie 分頁裡讀取（第一次查詢時會讀，存在這個瀏覽器 7 天，設定頁會顯示日期）；多個條件是「而且」，條件越多結果越少。底材如果剛好是網站的物品類型（例如 Ring、Amulet、Jewel）就會一起篩選，否則只在讀回來的這一頁裡依名稱挑，畫面會註明。查完會核對網站是否真的保留了每一個條件，沒保留會標「部分資料沒通過核對」。

### 裝備掃描（分享遊戲視窗，第三種查法）

線上角色的裝備不在本機存檔裡，用名稱或詞綴都查不到，這個查法改成看畫面。打開側邊欄先問「今天想搜尋什麼？」，選「裝備掃描」；按「選擇遊戲視窗並開始」，在 Chrome 自己的分享對話框裡選一次 D2R 視窗，然後把遊戲切到前景、自己把滑鼠移到每件裝備上停約半秒，程式就會把提示框裁下來、用同一套辨識讀出名稱記下來。程式**不會操作遊戲**（不移動滑鼠、不送按鍵、沒有熱鍵），只看你分享進來的畫面；每件裝備一筆，**完全相同的兩件只記一筆**。清單只存在記憶體裡，**關掉側邊欄就消失**，按「清除紀錄」清空，也可以按「下載 CSV」匯出（**不用先跑過任何查詢**）。每一筆都有「精準搜尋」和「模糊搜尋」兩顆按鈕，按下去只會**幫你填好表單，不會自己開始查詢**（模糊搜尋只有在讀到的本身就是底材時才會預填底材）。第一次使用會自動下載辨識模型（約 31.8 MB，和貼圖辨識共用同一套、只下載一次），下載會自己完成，畫面不會顯示進度或取消鈕。

每一筆右上角有一個小小的「✕」，按下去只刪掉那一筆（辨識錯了、不想留的都可以刪），不會開始查詢，掃描中或停止後都能刪；刪掉之後，同一件裝備再移上去會重新記一筆。程式沒有把握的那一筆會寫「不確定」，下面「可能是」後面列最多 5 個候選名稱，點對的那個才有名稱；每一筆沒有名稱的（不確定的、或沒認出名稱的）下面還有一個「輸入名稱」的小框，自己打中文或英文名稱再按「確定」或 Enter 也一樣（名稱要在對照表裡）。你點選或輸入的名稱會被「學習紀錄」記在這台電腦上，下次讀到一模一樣的字時排第一個。

掃描中側邊欄會直接告訴你它看到的狀況：遊戲把這個面板蓋住時，會提醒「遊戲視窗蓋住了這個面板，掃描會變慢、快速掠過的裝備可能漏掉」（改成視窗模式、和 Chrome 並排就會消失）；狀態列的「待辨識 N 件，約 M 秒」是還在排隊的裝備和大概要等多久（讀完第一件之後才有秒數）；「掃描統計」的「略過」是看到了但沒有新增紀錄的件數（同一件又看一次、或讀不出東西），「丟棄」是排隊超過 300 件而沒讀的件數。若有常規偵測未抓到的提示框（如半透明背景），在滑鼠靜止且無排隊工作時會啟動「備援偵測」（每約 3 秒最多一次），統計列的「備援偵測 N 次、救回 M 件」會記錄觸發與救回件數。

三個畫面（精準搜尋、模糊搜尋、裝備掃描）最上面的「← 返回」都是回到「今天想搜尋什麼？」那一頁，不會直接換成另一種查法，也不會開始查詢；你打的字還留在原本的欄位。在裝備掃描畫面按「← 返回」會一併停止掃描（清單還在），查詢進行中不能按。

## 常見訊息

| 訊息 | 意思 |
|---|---|
| 邀請碼無效或已停用 | 碼打錯，或已被停用；沒有儲存任何東西，請重新輸入（已經有儲存的碼時，到「開啟設定」更換） |
| 這組邀請碼的 N 次查詢已用完 | 這組碼的總次數用完了，不會重置，請找管理員換新的碼 |
| Traderie 要求驗證或登入 | 這個 Chrome 還沒登入 Traderie，或網站跳出安全驗證；按「開啟 Traderie」處理完，再按「我處理好了，重新查詢」 |
| 找不到這個裝備 | 查表、站內搜尋、底材清單都沒有符合的商品；試試英文全名，或用截圖 |
| 這些條件 Traderie 沒有對應的屬性 | 勾選的詞綴在 Traderie 的屬性清單裡找不到（或不只一個）；那幾列已自動取消勾選並變灰，確認後再查 |
| 無法取得 Traderie 屬性清單 | 在 Traderie 分頁裡讀屬性清單失敗（通常是沒登入或被網站擋住）；處理好登入後重新查詢 |
| 沒有符合條件的掛單 | 網站確實沒有符合全部條件的掛單；少勾幾個條件、放寬數字再查 |
| 被網站擋住（分頁旁的小標籤） | 那一段被 Traderie 擋住（通常是要登入），處理方式同上 |
| 查詢視窗被關閉，或「偵錯」被取消，查詢已停止 | 查詢中途關了那個最小化視窗，或按了黃色橫幅的「取消」；按「重新查詢」 |
| Chrome 在 30 秒內沒有回應（…），查詢已停止 | 查詢頁卡住沒回應（導覽最多等 60 秒）；按「重新查詢」 |

查詢頁跳出的提示框（alert、確認、離開頁面確認）會被自動關掉，不會卡住查詢。按「停止」會馬上關掉查詢視窗，不必等 Chrome 回應。側邊欄被關掉時會順手關掉查詢視窗；萬一視窗還是留下來，下次打開側邊欄（且只開著這一個側邊欄時）會把它關掉。

## 開發

```
node --test "extension/test/*.test.mjs"      # 迴圈與讀取邏輯
uv run pytest tests/test_extension_parity.py   # 解析結果和 Python 版逐筆相同
uv run python scripts/extension_e2e.py   # 真實 Chrome 端對端（預設無視窗，--headed 顯示視窗）
```

端對端測試需要專用 Chrome 已登入 Traderie（`uv run python scripts/login.py`），執行時會先關掉正在跑的專用 Chrome。

資料夾：本擴充功能的程式在 `extension/src/`；出貨的 `page/*.js` 打包時從專案根目錄的 `src/jev_ultrafast/` 複製過來（和本機 Python 版共用同一份頁面腳本）。

## 更新對照表

內建的「名稱 → 商品網址」「中文 → 英文」「底材清單」存在 `extension/src/traderie/data/items.json`，是某個時間點的拷貝。遊戲或網站新增物品後，重新產生：

```
uv run python scripts/build_item_tables.py
```

會開專用 Chrome 讀 Traderie 和 d2r.world，結果寫進上面那個檔案，並把「對不上的名單」寫成本機檔案 `artifacts/item_tables_report.json`（`artifacts/` 不進版本庫，是這台電腦上的產物）。表過期的後果只是少一層捷徑（退回搜尋），不會查錯。更新後要重新打包（`extension/build.py`）。
