# Jev Traderie 安裝與操作說明

## 1. 這是什麼？需要準備什麼？

Jev Traderie 是一個 Chrome 擴充功能（裝在瀏覽器裡的小工具）。
你輸入《暗黑破壞神 2：獄火重生》的裝備名稱，它會自動到 Traderie 網站查詢，
並在側邊欄整理成兩張表：**目前掛單**（現在有誰在賣、要價多少）和**近期成交**（最近實際成交的紀錄）。

你需要準備：

- **Google Chrome**（版本 116 以上）。
- **邀請碼**：向管理員索取，格式像 `inv-…`。
- **Traderie 帳號**：要在同一個 Chrome 先登入 <https://www.traderie.com>。沒登入時，網站不讓人按「Load More」（載入更多），「近期成交」也可能要求登入。

## 2. 安裝擴充功能

### 2-1 取得擴充功能資料夾

- **最簡單**：請管理員給你 `jev-traderie-extension.zip`，把它解壓縮到一個固定的資料夾（之後不要刪掉或搬走）。
- **自己打包**（需要已安裝 Python 工具 uv）：在專案根目錄執行

  ```
  uv run python extension/build.py
  ```

  完成後會產生資料夾 `extension/dist/`，同時產生 `extension/jev-traderie-extension.zip`。

### 2-2 安裝到 Chrome

1. 在 Chrome 網址列輸入 `chrome://extensions` 後按 Enter。
2. 打開右上角的「**開發人員模式**」。
3. 按「**載入未封裝項目**」，選到剛才解壓縮的資料夾（或 `extension/dist/`），按選取。
4. 清單裡出現「Jev Traderie」就完成了。可以按 Chrome 工具列的拼圖圖示，把它「釘選」起來，之後比較好找。
5. 在這個 Chrome 登入 Traderie（<https://www.traderie.com>）。

### 2-3 打開側邊欄

按工具列上的「Jev Traderie」圖示，畫面右側會展開側邊欄。

## 3. 第一次設定：輸入邀請碼

1. 側邊欄會顯示「**歡迎！先輸入邀請碼**」，貼上你的邀請碼。
2. 按「**確認並開始使用**」。這時邀請碼只是暫時顯示在畫面裡，**等你第一次查詢被伺服器接受後才會儲存**，所以打錯的碼不會被記下來。如果碼打錯或已被停用，會回到這個畫面並說明原因。
3. 之後想更換邀請碼，按右上角的「⚙ 設定」→「邀請碼」→「**更換**」，輸入新的碼再按「**確認**」；新的碼同樣要等下一次查詢被接受後才會儲存。

> **次數說明**：每組邀請碼有一個「**總次數**」上限（預設 100 次），**不是每天**。側邊欄最上方會顯示：在第一次查詢之前顯示「**已用 —**」；查詢中、查完及查詢停止後顯示「**已用 N/M**」（例如「已用 3/100」）；在查詢表單上則顯示「**剩 N 次**」。用完就不能再用，也不會重置，要再用請找管理員換新的碼。「一次」是一次完整查詢，不是一次點擊。


## 4. 查詢裝備

1. 在「**裝備名稱**」欄輸入名稱，可以用英文（例如 `Harlequin Crest`）或繁體中文。
   - 中文名稱會先用內建對照表換成英文；表裡沒有的中文名稱不會開始查詢，也不會用掉次數。
2. 「**多讀幾批**」用 − / + 按鈕選 0 到 5（預設 0）。數字越大讀到的資料越多，但花的時間也越長；每多一批，大約多等 8 秒（每批約讀 50 筆掛單、20 筆成交）。
3. 按「**開始查詢**」。想中途停下，按「**停止**」；停止後會顯示「已停止」，已經讀到的資料仍然保留。
4. 查詢時，Chrome 會另開一個**最小化的視窗**放 Traderie 並自動操作。
   - **查詢期間請不要關掉側邊欄，也不要關掉那個最小化視窗。**
   - 那個視窗上方的黃色橫幅「正在偵錯此瀏覽器」是正常的，查詢結束視窗會自動關閉。
5. 查詢中會顯示四個步驟：
   - ✔ 完成
   - ● 進行中
   - ○ 還沒開始
   - ✖ 失敗
   
   四個步驟分別是：找到商品、讀取目前掛單、讀取近期成交、核對資料。輸入欄、批數和設定都會鎖住。

### 結果頁怎麼看

查完後，側邊欄會分成幾部分：

1. **摘要行**：上方一行會寫「查詢：名稱」，右邊有「**重新查詢**」按鈕（點它回到輸入畫面，名稱保留，舊結果在你下次開始查詢前還看得到）。
2. **核對結果**：下一行會寫：
   - 「**✔ 資料已核對 · 查詢方式 · 讀取時間**」表示全部通過檢查；
   - 「**⚠ 部分資料沒通過核對 ›**」表示有資料沒通過（點它展開看哪裡沒通過）。
3. **查詢方式**：核對結果下方的一行會寫「查詢方式」，說明用了以下哪一種方法找到商品。如果用過「底材清單」，下面一行會一直保留「**顯示的是底材，沒有依品質篩選**」的提醒。
   - **查表直接開啟**：名稱在內建對照表裡，直接開商品頁，再檢查頁面標題是不是那個商品，不是就改用搜尋。
   - **站內搜尋**：Jev 在 Traderie 搜尋欄輸入名稱並挑結果。
   - **底材清單**：搜尋出現「No results could be found」時，Jev 從固定的底材清單挑一個（例如查 Rare Ring 會挑 Ring），再搜一次；清單裡沒有適合的，就顯示「找不到這個裝備」，並建議「試試英文全名，或用截圖」。
4. **結果分頁**（兩張表）：
   - 「**目前掛單 N**」和「**近期成交 N**」（N 是筆數，開了篩選會變成「12/50」，意思是「留下 12 筆／讀到 50 筆」；那一段沒讀成功時，旁邊會標「讀取失敗」或「被網站擋住」）。
   - 清單上面不再顯示筆數和讀取時間；只有那一段是空的或沒讀成功時，才會多一行說明原因（例如「目前沒有掛單」、「需要登入」）。
   - 超過 10 筆時每頁 10 筆，用「**‹ ›**」換頁。
   - 分頁列正下方有一排三個等寬按鈕，**作用在你目前選到的分頁**（切換分頁，按鈕就換成對那一段動作；那一段沒有資料時前兩個是灰的）：
     - 「**下載 CSV**」：下載成檔案（CSV 是試算表可開啟的純文字表格）。
     - 「**複製**」：複製整張表，貼到 Excel 或 Google 試算表會自動分欄。
     - 「**前往網站**」：在新分頁打開這個分頁讀取的 Traderie 頁面（查詢完成後才能按）。
     - 「複製」和「下載 CSV」都包含**篩選後的全部筆數**（沒開篩選就是讀到的全部），不只目前這一頁。
   - **目前掛單**：每筆用兩行顯示——第一行是要價和賣家，第二行是刊登時間、平台／模式／天梯，還有遊戲版本，有的話再加上高符文價值和防禦。
   - **近期成交**：每筆也是兩行——第一行是成交物品和成交價格，第二行是成交時間、平台／模式／天梯、遊戲版本。
   - **篩選**：只想看 PC、Softcore、Ladder 之類的？按右上角「⚙ 設定」→「**篩選**」，選平台、模式、天梯、遊戲版本（也可以按「**常用：PC · Softcore · Ladder**」，「**清除**」會全部取消）。兩個分頁都會套用；改篩選**不會重新查詢，也不會用掉次數**。開了篩選時，分頁上方會有一行「篩選中：…　隱藏 N 筆　改」，點「改」回設定。網站沒標示某一項的資料，那一項有篩選時會被隱藏（那一行會告訴你有幾筆是這種）。如果篩到一筆都不剩，會看到「篩選後沒有符合的資料」和「清除篩選」。如果留下的不到 10 筆，可以回首頁把「多讀幾批」調高再查一次。

## 5. 用截圖查名稱（辨識圖片文字）

不想打字時，可以拿物品提示框的截圖來辨識名稱。

1. 放入圖片，三種方式擇一：
   - 按名稱欄右邊的「**📷**」按鈕，選一張截圖；
   - 在側邊欄按 **Ctrl+V** 貼上；
   - 把圖片拖進側邊欄。
2. 放進圖片後，名稱欄下方會出現**小縮圖**（點一下放大，可按「✕」收起；沒有圖片時看不到）。
3. 預設「放入圖片後自動辨識」是**開著的**：模型已經下載時，放入圖片就會自己讀，不用按按鈕。只有在**關掉自動辨識、模型還沒下載，或你在圖上拖了框想重讀**時，才會出現「**辨識**」鈕。
4. 在圖上拖一個框，只框住物品名稱那幾行，通常更準更快（可省略）。
5. 縮圖下方有「**看辨識出的文字**」小連結，可以看程式讀到了什麼。
6. **第一次**使用會自動下載辨識模型（約 31.8 MB），畫面會顯示進度與取消鈕。
7. 辨識完成後，最像的名稱會自動填進「**裝備名稱**」欄，旁邊標示「**● 來自截圖，請確認**」；還有 1 到 2 個候選名稱，按鈕上寫「英文（中文）」（例如 `Diadem（權冠）`、`Defender（防禦盾）`；表裡沒有中文名時只寫英文），點一下就改填那個。
8. **程式只會幫你填名稱，不會自動查詢。**請確認名稱正確後，自己按「**開始查詢**」。

注意事項：

- 模型下載一次就存在這個瀏覽器裡，之後**不用網路也能辨識**；圖片只在你的電腦上處理，不會傳出去。
- 下載失敗時會顯示原因，再按一次「辨識」就會重新下載；模型紀錄會在引擎啟動失敗時自動清除。
- 稀有、魔法、手工裝備的名稱是隨機的，Traderie 沒有這種商品，這時只會認出「底材」（戒指、護身符、特大咒符…）。這類裝備請用下一節的「模糊搜尋（適用黃・藍・白裝）」查法。
- **名稱比對只支援繁體中文與英文**；其他語言的遊戲，如果截圖上沒有英文名稱，讀出來的字會顯示在「看辨識出的文字」，名稱要自己手動輸入。
- 辨識不一定每次都對，一定要自己確認。

## 5-2. 模糊搜尋（適用黃・藍・白裝，用詞綴找）

名稱是隨機的裝備（黃裝＝稀有、藍裝＝魔法、白裝＝普通）沒辦法用名稱查，要用它身上的底材與詞綴找。

1. 打開側邊欄先問「今天想搜尋什麼？」，選「模糊搜尋」。
2. 貼上或拖入裝備截圖，也可以手動在「底材」欄輸入。程式會把底材填進「底材」欄，並列出一排詞綴條件。**底材欄已支援繁體中文輸入自動轉換**（例如輸入「戒指」、「權冠」會自動轉為「Ring」、「Circlet」代入搜尋，不可空）。**截圖讀出、數字有把握的詞綴會自動勾上。**
3. 勾你想用的條件（例如施法速度、所有抗性）。每一列可以改最小值、最大值。標著「**?**」的列代表圖上的數字讀得不確定（常見是 % 被讀成多餘的數字），請自己確認。灰色、勾不了的列表示 Traderie 沒有這個屬性。
4. 選品質（黃裝、藍裝、白裝，或不指定）。
5. 按「**開始查詢**」。這個查法**不會扣邀請碼的次數**，只讀網站的第一頁（最多 50 筆），查完會告訴你網站有沒有真的套用你的條件。

提醒：條件越多結果越少（多個條件是「而且」）；數字來自圖片辨識，查之前一定要自己看過。這個查法要用到你已登入的 Traderie 分頁，第一次查詢時會讀取 Traderie 的屬性清單。

## 5-3. 裝備掃描（第三種查法）

線上角色的裝備不在本機存檔裡，用名稱或詞綴都查不到。這個查法改成「看畫面」：你自己在遊戲裡把滑鼠移到每件裝備上，程式讀你分享進來的畫面，幫你一件一件記下來。

1. 打開側邊欄，在「今天想搜尋什麼？」選「**裝備掃描**」。
2. 按「**選擇遊戲視窗並開始**」，在 Chrome 自己的分享對話框裡選 D2R 視窗（這一步只有你自己能做，要分享一次）。
3. 把遊戲切到前景、蓋住 Chrome（建議用「視窗化全螢幕」或視窗模式），在遊戲裡把滑鼠移到每件裝備上，停約半秒。
4. 回到側邊欄看清單。想查某一件，就按那一筆的「**精準搜尋**」或「**模糊搜尋**」，確認表單後自己按「**開始查詢**」。

要知道的幾件事：

- 程式**不會操作遊戲**：不移動滑鼠、不送出任何按鍵或點擊，也沒有熱鍵；它只讀你分享進來的那張畫面。
- 每件裝備只記一筆，**完全相同的兩件只記一筆**。
- 清單只存在記憶體裡，**關掉側邊欄就消失**；按「**清除紀錄**」可以清空。
- 清單可以按「**下載 CSV**」匯出，**不需要先跑過任何一次查詢**。
- 每一筆的「**精準搜尋**」和「**模糊搜尋**」按下去只會**幫你填好表單，不會自己開始查詢**（模糊搜尋只有在讀到的本身就是底材時才會預填底材）。
- 「**掃描統計**」會顯示每秒畫面張數等數字，方便你知道掃描有沒有在動。
- **第一次**使用會自動下載辨識模型（約 31.8 MB，和貼圖辨識共用同一套，只下載一次），畫面會顯示進度與取消鈕。

## 6. 常見訊息

| 你看到的訊息 | 意思與處理方式 |
|---|---|
| 邀請碼無效或已停用 | 碼打錯，或已被停用。沒有儲存任何東西，請重新輸入；如果已經有儲存的碼，到「⚙ 設定」→「邀請碼」→「更換」。 |
| 這組邀請碼的 N 次查詢已用完 | 這組碼的總次數用完了，不會重置。請找管理員換新的碼。 |
| Traderie 要求驗證或登入 | 這個 Chrome 還沒登入 Traderie，或網站跳出安全驗證。按「**開啟 Traderie**」在新分頁處理完，再回側邊欄按「**我處理好了，重新查詢**」（不會自動開始）。 |
| 找不到這個裝備 | 查表、站內搜尋、底材清單都沒有符合的商品。試試英文全名，或用截圖。 |
| 被網站擋住（分頁旁的小標籤） | 那一段被 Traderie 擋住（通常是要登入）。處理方式同「Traderie 要求驗證或登入」。 |
| 查詢視窗被關閉，或「偵錯」被取消，查詢已停止 | 查詢中途關了那個最小化視窗，或按了黃色橫幅的「取消」。按「**重新查詢**」重新開始。 |
